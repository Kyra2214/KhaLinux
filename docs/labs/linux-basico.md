# Linux: primeiros comandos

Trilha: linux · Dificuldade: iniciante · Pré-requisitos: nenhum

Lab iniciante. Todos os exercícios são respondidos com comandos do próprio RootFS (`ls`, `pwd`, `wc`, aritmética do Bash); nenhum serviço é iniciado e nenhuma rede é usada. Objetivo: se orientar no shell e ler a ajuda (`--help`, `man`).

## Exercícios

- `ls-ocultos` — Arquivos ocultos (iniciante)
- `diretorio-atual` — Onde estou (iniciante)
- `contar-linhas` — Contando linhas (iniciante)
- `aritmetica` — Aritmética no shell (iniciante)

## Escopo

Sem serviços, sem alvos externos e sem rede. As respostas são conferidas por SHA-256 da resposta normalizada (ver `docs/labs.md`).
