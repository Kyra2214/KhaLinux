# Rede: loopback e ping

Trilha: rede · Dificuldade: iniciante · Ferramentas: iproute2, iputils-ping · Pré-requisitos: nenhum

Lab iniciante sobre loopback: endereço 127.0.0.1, interface `lo`, prefixo /8 e a opção `-c` do ping. Tudo local; nenhum pacote sai do aparelho.

## Serviços

Nenhum.

## Exercícios

- `ip-loopback` — Endereço de loopback (iniciante)
- `interface-lo` — Interface de loopback (iniciante)
- `cidr-loopback` — Prefixo da rede 127 (iniciante)
- `ping-contagem` — Limitar o ping (iniciante)

## Escopo

Só loopback; nenhum alvo externo. Nenhum laboratório usa `nmap` (exigiria confirmação de escopo). Respostas conferidas por SHA-256 da resposta normalizada (ver `docs/labs.md`).
